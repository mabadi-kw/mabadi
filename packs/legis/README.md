# حزم التشريعات — `mabadi-legis-pack` الإصدار 1.0

هذه الحزم تضم تشريعات مكتبة «مبادئ التمييز»، وعددها 238 تشريعًا:
- 152 قانونًا ومرسومًا بقانون؛
- 86 مرسومًا ولائحة وقرارًا.

صُمّمت للاستعمال في تطبيق «عمّالي» بطريقة حزم المبادئ نفسها.

تُولَّد الحزم بالأمر `python3 tools/export/legis_packs.py`، وتُفحص بالأمر `python3 tools/export/check_legis_packs.py`. الفحص يتأكد أن كل فقرة في الحزم موجودة حرفيًا في نصوص المكتبة.

## الملفات
- **`mabadi-legis-index_v1.0.json`**: الملف التعريفي. فيه قائمة التشريعات، ولكل تشريع:
  - المعرّف والنوع والرقم والسنة والعنوان والحالة؛
  - عدد المواد، وعدد المواد النافذة، وعدد ما يحتاج منها مراجعة؛
  - حجم النص بالأحرف وحجم السجل بالبايت؛
  - المصدر، وتاريخ النص، وهل روجع على الجريدة الرسمية؛
  - ملف الحزمة الذي يضمه.

  وفيه أيضًا قائمة الحزم مع حجم كل منها وبصمتها (sha256).
- **`mabadi-legis_<المجموعة>_v1.0.json`**: حزمة لكل مجموعة، والمجموعات عشر: الجزائي، والمدني والعقاري، والتجاري، والتجارة البحرية، والمرافعات والقضاء، والأحوال الشخصية، والقضاء والوظيفة والعمل والتأمينات، والجهاز الإداري للدولة، والدستور والجنسية والانتخاب، وجهات وفئات خاصة.

## التشريع
| الحقل | المعنى |
|---|---|
| `id` | المعرّف الثابت، مثل `LAW-6-2010` أو `REG-…` |
| `key` | الرقم/السنة |
| `category` | `law` للقوانين والمراسيم بقوانين، و`reg` للمراسيم واللوائح والقرارات |
| `type`، `number`، `year` | النوع والرقم والسنة |
| `title`، `short_title` | العنوان الرسمي كما ورد، والاسم المختصر |
| `status` | `نافذ` أو `معدّل` أو `ملغى` |
| `repealed_by` | التشريع الملغي ومادته، إن كان التشريع ملغى |
| `issued` | تاريخ الإصدار بالتاريخين الميلادي والهجري |
| `source.kind` | `gazette` للجريدة الرسمية، ومعه العدد والتاريخ والملحق؛ `moj_edition` لطبعة وزارة العدل «مجموعة التشريعات الكويتية»، فبراير 2011؛ `pdf_file` لغيرهما |
| `text_as_of` | تاريخ النص: تاريخ العدد في الجريدة، أو `2011-02` لنصوص الطبعة |
| `amendments_applied_until` | تاريخ آخر تعديل منشور في الجريدة ومسجل في المكتبة |
| `amended_by`، `amends`، `repeals` | ما عدّل التشريع، وما يعدّله التشريع أو يلغيه |
| `verified_against_gazette` | `true` فقط لما استُخرج من ملف الجريدة الرسمية نفسه وطوبق مع صور صفحاته. وغيره `false`، والسبب في `verification_note` |
| `known_issues` | ملاحظات معروفة على المصدر |
| `preamble`، `signature`، `structure` | الديباجة، والتوقيع، والأبواب والفصول مع نطاق موادها |
| `articles` | المواد |

## المادة
| الحقل | المعنى |
|---|---|
| `id` | المعرّف الثابت للمادة |
| `number`، `suffix`، `label` | الرقم، و«مكرر» ونحوها، ورقم المادة كما ورد في المصدر |
| `part` | `مواد الإصدار` لمواد مرسوم الإصدار |
| `chapter_path` | الباب والفصل |
| `status` | `نافذة` أو `معدّلة` أو `مضافة` أو `ملغاة` |
| `text_in_force` | النص النافذ: فقرات حرفية من نص منشور كامل، أو `null` (انظر القواعد) |
| `text_in_force_basis` | مصدر النص النافذ |
| `original_text` | نص المادة قبل تعديلها أو إلغائها بتشريع نُشر في الجريدة بعد الطبعة |
| `amendments[]` | التعديلات اللاحقة للطبعة. لكل تعديل: التشريع المعدِّل ومادته وتاريخه، وطريقة التعديل ونطاقه، وجملة التعديل (`enacting_clause`)، والنص المنشور (`published_text`) |
| `repealed`، `repealed_by` | علامة الإلغاء، والتشريع الملغي ومصدر المعلومة: الجريدة الرسمية، أو حاشية الطبعة |
| `insert_after` | للمواد المضافة: المادة التي تُدرج بعدها |
| `edition_notes` | حواشي طبعة الوزارة كما وردت. وفيها أحيانًا نص المادة قبل تعديلات سابقة للطبعة |
| `edition_note_refs` | التشريعات المذكورة في الحاشية، مستخرجة آليًا للتيسير. المرجع نص الحاشية نفسه |
| `needs_review`، `review_reasons` | المادة تحتاج مراجعة بشرية، والسبب |

## قواعد النزاهة
- لا يُكتب نص لم يرد حرفيًا في مصدر منشور.
- إن استُبدلت مادة كاملة بنص منشور في الجريدة، صار ذلك النص هو النص النافذ، وحُفظ النص السابق في `original_text`.
- إن كان التعديل جزئيًا، أي فقرة أو بند أو عبارة أو إضافة فقرة:
  - لا يُدمج آليًا؛
  - يبقى `text_in_force = null`؛
  - يُعطى نص التعديل كما نُشر، وتُعلَّم المادة `needs_review`.
- نصوص طبعة 2011 تشمل التعديلات حتى تاريخها، كما تذكرها حواشيها. وما صدر بعدها لا يظهر إلا إن كان مسجلًا في المكتبة من الجريدة. لذلك تحمل كل هذه التشريعات `verified_against_gazette: false`.
