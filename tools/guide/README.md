# دليل الاستخدام والفيديو التعريفي — اقرأني

يُولَّد الدليل المصوّر (PDF) والفيديو التعريفي من التطبيق نفسه آليًا، فيُعاد توليدهما بأمر واحد كلما تغيّرت الواجهة.

## المتطلبات (مرة واحدة)
```
cd tools/guide
npm install
npx playwright install chromium
```
لا يحتاج أي اتصال خارجي أثناء التوليد: الخطوط في `tools/guide/fonts/`، والتطبيق يُخدَم من المستودع نفسه، وكل طلب خارجي يُمنع.

## الأوامر
| الأمر | ما يفعله |
|---|---|
| `npm run guide` | يلتقط الصور (حاسوب 1280×800 وآيفون 390×844)، ويبني `docs/guide.pdf`، ويتحقق أن جدول `GUIDE` في `app.js` مطابق لصفحات الفصول، وينبّه إن اختلفا |
| `npm run guide:fix` | مثل السابق، ويحدّث جدول `GUIDE` في `app.js` تلقائيًا |
| `npm run video` | يسجّل الفيديو التعريفي إلى `docs/intro.mp4` وصورة الغلاف `docs/intro.jpg` (يحتاج `ffmpeg`) |
| `npm run test` | يتحقق أن روابط «الدليل» في كل قسم تفتح الصفحة الصحيحة، وأن الدليل والفيديو موجودان |

خيار `--no-shots` مع `node build-guide.mjs` يعيد بناء PDF من الصور الملتقطة سابقًا دون التقاط جديد.

## الملفات
- `chapters.mjs`: نصوص الفصول (الوظيفة، الخطوات، التنبيهات) واللقطات. **عدّل النصوص هنا فقط.**
- `build-guide.mjs`: الالتقاط، وصفحة HTML، والطباعة إلى PDF، والتحقق من الجدول.
- `build-video.mjs`: تسجيل الفيديو.
- `lib.mjs`: الخادم المحلي والمتصفح والخطوط.
- المخرجات في `docs/` (لا يخزّنها عامل الخدمة على الجهاز)، والملفات الوسيطة في `tools/guide/out/` (غير مرفوعة).

## قواعد
- لا رقم إصدار داخل الدليل ولا الفيديو.
- البيانات في اللقطات مبادئ حقيقية من المكتبة بنصها ومصدرها، والمحفوظات التجريبية تُنشأ محليًا دون أي اسم شخص.
