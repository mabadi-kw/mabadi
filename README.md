# مبادئ التمييز

مكتبة مبادئ محكمة التمييز الكويتية: بحث في نصوص المبادئ، ونسخها وطباعتها، مع صورة الصفحة الأصلية لكل مبدأ. تعمل على الجوال والحاسوب، ودون اتصال بعد أول زيارة.

**الموقع:** https://mabadi-kw.github.io/mabadi/

مبادرة شخصية مجانية غير تجارية، وليست جهة رسمية.

## المحتوى
- 32,573 مبدأً من 13 مجموعة: «المبادئ القانونية التي قررتها محكمة التمييز خلال أربعين عامًا» (العمالي، التجاري، المدني، الإداري، المرافعات، الجزاء، الإجراءات الجزائية، الأحوال الشخصية)، و«المستحدث» (الإصداران 11 و12)، و«مرجع قواعد العمالي حتى ديسمبر 2023».
- النطاق: مجموعات أحكام محكمة التمييز الرسمية وإصدارات مكتبها الفني، ومجلة القضاء والقانون، وقرارات غرفة المشورة. المؤلفات الخاصة خارج المكتبة.

## قواعد النزاهة
1. نص كل مبدأ حرفي كما في مصدره: لا يُعاد صياغته ولا يُختصر ولا يُصحَّح إملائيًا.
2. لا يُخترع مبدأ ولا يُخمَّن حرف. ما شُكّ فيه يُعلَّم «يحتاج مراجعة» مع سببه.
3. رقم الطعن وتاريخ الجلسة يُفحصان آليًا ويُقارنان بين المصادر.
4. كل مبدأ مربوط بصورة صفحته. المرجع عند أي شك هو النص المطبوع في المصدر.

## الحزم (البيانات)
- `packs/`: ملف JSON لكل دائرة بصيغة `mabadi-pack` (الإصدار 1.5)، والتجاري في ثلاثة أجزاء.
- `packs/manifest.json`: يسرد الحزم بإصدارها وحجمها وبصمتها (sha256) وأعدادها، ليتحقق المستهلك من وجود تحديث.
- المعرّفات ثابتة لا تتغير ولا يُعاد استعمالها. العنصر المحذوف يُعلن في `deleted_items`.

## بنية المستودع
